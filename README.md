# LED Wall Alignment Tool

Визуальный генератор разметки для LED-стен. Один экран, никаких лишних сложностей.

## Возможности

**Параметры модуля**
- Шаг пикселя (pitch) с пресетами P0.9–P10
- Физический размер модуля (мм) / размер в пикселях
- Авторасчёт px из мм при заблокированной синхронизации

**Сетка**
- Количество модулей по горизонтали и вертикали
- Расчёт по желаемому физическому размеру стены

**Маркеры**
- На каждый модуль: крест, плюс, круг
- Полноэкранные: диагонали (↖↘, ↗↙), окружность
- Цвет на выбор (7 цветов)
- Настраиваемая граница модуля: толщина и цвет, рисуется внутрь

**Идентификация**
- Alpha-Numeric / Numeric / без текста
- Выбор стартового угла

**Тест-паттерны**
- Шахматная доска (настраиваемые цвета)
- Серая полоса, цветная полоса RGB

**Название**
- Текст по центру, цвет текста/фона, прозрачность
- Info-лейбл (размер, разрешение, модули, pitch)

**Экспорт**
- **PNG** — растровое изображение
- **SVG** — векторная графика
- **PDF** — через браузер (Ctrl+P)

**Удобство**
- Зум/пан (колесо + drag)
- Undo/Redo (Ctrl+Z / Ctrl+Shift+Z)
- Автосохранение в localStorage
- Адаптивный интерфейс

## Использование

Откройте `index.html` в любом современном браузере. Сервер не требуется.

## Стек
