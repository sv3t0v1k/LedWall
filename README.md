# LED Wall Alignment Generator Pro

Визуальный генератор разметки для LED-стен. Позволяет настроить параметры модулей и сетки, наложить маркеры юстировки (крест, плюс, круг, диагонали, окружность), выбрать тест-паттерны и экспортировать результат в PNG.

## Возможности

- **Параметры модуля** — шаг пикселя (pitch), физический размер модуля, размер в пикселях, авторасчёт при заблокированной синхронизации
- **Сетка стены** — количество модулей по горизонтали и вертикали, расчёт по желаемому физическому размеру стены
- **Маркеры** — крест, плюс, круг на каждый модуль; полноэкранные диагонали и окружность
- **Идентификация модулей** — Alpha-Numeric / Numeric / без текста, выбор стартового угла
- **Тест-паттерны** — шахматная доска (с настраиваемыми цветами), серая полоса, цветная полоса RGB
- **Название экрана** — настраиваемый текст по центру изображения с цветом, фоном и прозрачностью
- **Info-лейбл** — физический размер, разрешение, количество модулей и шаг пикселя
- **Экспорт** — PNG (с масштабированием при превышении 16384 px), JSON-конфигурация, импорт конфигурации
- **Автосохранение** — состояние сохраняется в localStorage

## Использование

Просто откройте `index.html` в любом современном браузере. Всё работает на стороне клиента, сервер не требуется.
