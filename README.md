# LED Wall Alignment Generator Pro

Визуальный генератор разметки для LED-стен. Несколько экранов, слои, зум/пан, поворот модулей, BOM, экспорт в PNG/SVG/PDF.

## Возможности

### Экраны
- Несколько экранов в одном проекте (добавление/удаление, вкладки)
- Настраиваемые отступы между экранами (мм) с визуальной подписью
- Цвет разметки, толщина и цвет границы, ID — свои для каждого экрана

### Параметры модуля (на экран)
- Шаг пикселя (pitch) с пресетами P0.9–P10
- Физический размер модуля (мм) / размер в пикселях
- Авторасчёт px из мм при заблокированной синхронизации
- Сетка стены: кол-во модулей + расчёт по желаемому физ. размеру
- Пресеты (P0.9–P10) с автоустановкой модуля

### Маркеры юстировки
- На каждый модуль: крест, плюс, круг
- Полноэкранные: диагонали (↖↘, ↗↙), окружность
- Цвет на выбор (7 цветов), свой для каждого экрана
- Поворот модуля на 180° (Pro-режим, клик по модулю)
- Настраиваемая граница модуля: толщина и цвет, рисуется внутрь

### Идентификация
- Alpha-Numeric / Numeric / без текста
- Выбор стартового угла нумерации

### Тест-паттерны
- Шахматная доска (настраиваемые цвета)
- Серая полоса, цветная полоса RGB

### Название экрана
- Текст по центру, цвет текста/фона, прозрачность
- Info-лейбл на изображении (размер, разрешение, модули, pitch)

### Слои (Pro-режим)
- Отключение видимости: сетка, модули, маркеры, ID, названия, info, линейка, аннотации

### Зум и панорамирование
- Колесо мыши, клавиши +/−/0
- Drag для панорамирования
- Индикатор уровня зума, кнопки сброса
- Канвас автоматически подстраивается под размер окна + скролл при переполнении

### Линейка
- Интерактивные измерения на канвасе (расстояние в px и мм/м)
- Сохраняются между сессиями

### BOM / Спецификация (Pro)
- Таблица модулей по экранам
- Расчёт общего веса и энергопотребления

### Аннотации
- Инфраструктура для текстовых и стрелочных пометок на схеме

### Hotspots
- Клик по модулю — тултип с информацией: экран, ID, позиция, поворот, pitch

### Undo/Redo
- Ctrl+Z / Ctrl+Shift+Z, до 30 шагов

### Экспорт
- **PNG** — растровое изображение (с масштабированием при превышении)
- **SVG** — векторная графика (корректный SVG 1.1, открывается в Illustrator)
- **PDF** — открывает страницу с авто-печатью (Ctrl+P → Сохранить как PDF)
- **JSON** — экспорт/импорт полной конфигурации проекта + миграция из старых форматов

### Прочее
- Простой / Профессиональный режим (тоггл в хедере)
- Автосохранение в localStorage
- Адаптивный интерфейс

## Использование

Откройте `index.html` в любом современном браузере. Сервер не требуется.
