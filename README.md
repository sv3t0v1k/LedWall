# LED Wall Alignment Generator Pro

Визуальный генератор разметки для LED-стен. Поддерживает несколько экранов в одном проекте, экспорт в PNG, SVG и PDF, линейку для измерений.

## Возможности

### Экраны
- **Несколько экранов** — добавление/удаление экранов, переключение между ними
- **Отступы** — настраиваемые физические зазоры между экранами (мм)
- **Переключение** — вкладки для быстрого переключения между экранами

### Параметры модуля (на экран)
- Шаг пикселя (pitch) с пресетами (P0.9–P10)
- Физический размер модуля (мм) / размер в пикселях
- Авторасчёт px из мм при заблокированной синхронизации

### Сетка
- Количество модулей по горизонтали и вертикали
- Расчёт по желаемому физическому размеру стены

### Маркеры юстировки
- На каждый модуль: крест, плюс, круг
- Полноэкранные: диагонали (↖↘ и ↗↙), окружность
- Цвет разметки (7 цветов)

### Идентификация модулей
- Alpha-Numeric, Numeric или без текста
- Выбор стартового угла (Top Left / Right, Bottom Left / Right)

### Тест-паттерны
- Шахматная доска (с настраиваемыми цветами)
- Серая полоса, цветная полоса RGB

### Название экрана
- Текст по центру изображения
- Цвет текста, фона и прозрачность

### Линейка
- Интерактивные измерения на канвасе
- Расстояние в px и мм/м
- Сохраняются между сессиями

### Экспорт
- **PNG** — растровое изображение (1:1 или с масштабированием)
- **SVG** — векторная графика
- **PDF** — открывает страницу для сохранения через браузер (Ctrl+P → PDF)
- **JSON** — экспорт/импорт конфигурации проекта

### Прочее
- Автосохранение в localStorage
- Info-лейбл на изображении (физ. размер, разрешение, модули, pitch)

## Использование

Откройте `index.html` в любом современном браузере. Сервер не требуется.

## Стек

Чистый HTML + CSS + JavaScript (Canvas 2D)  
Шрифт Inter (Google Fonts)
