О проекте

GenMap Toolkit создаётся техническими специалистами для технических специалистов

Технический продакшен

Инструменты для концертного и студийного оборудования, проверенные в реальных проектах

Без зависимостей

Чистый HTML + CSS + JS — открывай и работай. Никаких сложных установок или серверов

Постоянное развитие

Библиотека инструментов растёт. Следите за обновлениями и предлагайте свои идеи

Open Source

Исходный код открыт. Сообщество может участвовать в разработке и улучшении инструментов
