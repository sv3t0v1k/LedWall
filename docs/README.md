# Документация GenMap Toolkit

## Архитектура

Проект построен по принципу **минимализма и нулевых зависимостей**.
Каждый инструмент — самодостаточная HTML-страница в папке `tools/`.

### Главная страница

- `index.html` — точка входа, лендинг с навигацией к инструментам
- Canvas-фон на чистом JS — анимированные геометрические линии (стиль «технический блюпринт»)
- Горизонтальная карусель инструментов с плавным скроллом
- Плавное появление страниц (fade-in через CSS transition)

### Инструменты

Каждый инструмент:
- Лежит в `tools/<tool-name>/index.html`
- Не зависит от внешних файлов (все стили и скрипты встроены)
- Содержит ссылку назад на главную
- Имеет fade-in при загрузке

### Навигация

Все ссылки на инструменты — нативные `<a href="...">`. При клике браузер выполняет обычный переход.
На целевой странице стоит `body { opacity: 0; transition }` — при загрузке добавляется класс `loaded`, и страница плавно появляется.

## Карусель инструментов

- Основана на `transform: translateX` с `transition: .7s cubic-bezier`
- Управление: стрелки, колёсико мыши, drag, клавиатура (← →)
- Dots-навигация снизу
- Карточки `coming-soon` заблокированы (opacity + cursor)

## Добавление нового инструмента

1. Создать `tools/<tool-name>/index.html`
2. Убедиться, что страница самодостаточна
3. Добавить на страницу:
   - `body { opacity:0; transition }` + `body.loaded` на DOMContentLoaded
   - Ссылка `../../index.html` для возврата
4. Добавить карточку в карусель на главной (`index.html`)
5. Обновить таблицу в `README.md`
