# Правила работы с GenMap Toolkit

## 1. Ветки

```
main                    — стабильная версия (только после моего согласования)
feat/<название>         — новая фича/инструмент
fix/<название>          — багфикс
```

**Любая работа** (фича, багфикс, рефакторинг) выполняется **только** в отдельной ветке.
Исключение: только если я явно сказал «работай в основной ветке».

## 2. Процесс

```
1. Создать ветку от main:     git checkout -b feat/название
2. Разработка                 написать код, проверить в браузере
3. Тестирование               через Playwright (или вручную, если сказано)
4. Передать мне на проверку   я смотрю, говорю «ок» или прошу правки
5. Коммит, пуш               после моего «да»
6. Переключиться на main      git checkout main
7. Смержить ветку             git merge feat/название
8. Запушить main              git push origin main
9. Удалить локальную ветку    git branch -d feat/название
```

## 3. Структура файлов

### Новый инструмент

```
tools/<tool-name>/
├── index.html              ← самодостаточная страница (все стили и js inline)
└── data/
    └── <data>.json         ← если нужны пресеты/библиотека (опционально)
```

### Каждый инструмент обязан иметь

- `body { opacity: 0; transition: opacity .5s ease }` + класс `loaded` на DOMContentLoaded
- Кнопка «назад» в шапке: `<a href="../../index.html">`
- Toast-уведомления (функция `toast()`)
- Ripple-эффект на кнопках
- Адаптивность (3 брейкпоинта)

### При добавлении на главную

1. Карточка в карусели `index.html` (активная — с `<a>`, неактивная — с `coming-soon`)
2. Строка в таблице `README.md`
3. Описание в `docs/context.md`

## 4. Стиль кода

- Без комментариев (код самодокументируемый)
- ES5 (var, function), без транспиляции
- Вложенные функции, IIFE обёртка
- `'use strict'` в начале каждого скрипта
- Никаких внешних зависимостей, кроме:
  - Google Fonts (Inter)
  - Font Awesome 6 (CDN)
- Все вычисления — на клиенте, в браузере

## 5. Ссылки на file://

На `file://` протоколе ссылки должны указывать полный путь до файла:

```
✅ <a href="tools/led-wall/index.html">
❌ <a href="tools/led-wall/">
```

Иначе браузер показывает список файлов в директории вместо страницы.
Это касается и кнопки «назад» (`../../index.html`, не `../../`).

## 6. Данные

- JSON-файлы: `data/<name>.json`
- Загрузка: `fetch()`, fallback — встроенный массив DEFAULT_...
- Кастомные добавки пользователя: `localStorage`
- Состояние сессии: `localStorage` (автосохранение при каждом изменении)
- Экспорт: CSV (буфер), JSON (скачать файл), PDF (window.print)

## 7. Тестирование

- Инструмент должен открываться без ошибок в консоли
- Все поля ввода должны принимать корректные значения и игнорировать некорректные
- Расчёты проверяются на здравый смысл (рукописный расчёт или известные значения)
- Адаптивность: проверить на 1024px, 768px, 480px
- Экспорт/импорт: проверить что скачивается/копируется
